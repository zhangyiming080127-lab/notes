## Week 1 - History
- One writing system can be used by many languages
- Cuneiform is one of the earliest known writing systems

## Week 2 - Bits and Bytes
- 1 byte = 8 bits
- Binary only uses 0 and 1 to represent data

## Week 3 - Number Systems
- We use base 10 (decimal) daily
- Computers work with base 2 (binary)

## Week 4 - Text Encoding
- ASCII is an older character encoding
- Unicode supports almost all languages in the world

## Week 5 - Boolean Logic
- AND, OR, NOT are basic boolean operators
- Boolean results can only be True or False
